### PHẦN 1: ANDROID BRIDGE APK (`ai.os.bridge`) - KOTLIN
Tạo project Android tối giản (không cần Activity giao diện phức tạp, chỉ cần 1 Activity trống để xin quyền nếu cần và 1 **Foreground Service** chạy ngầm bất tử).
1. **Local HTTP/JSON Server nội bộ (`127.0.0.1:8765`):** Dùng `NanoHTTPD` hoặc `Ktor` (hoặc `ServerSocket` thuần Java để nhẹ nhất, không phụ thuộc thư viện nặng) lắng nghe các endpoint sau:
   - `GET /screenshot`: Chụp toàn màn hình không cần Accessibility Service hay MediaProjection popup. Sử dụng Reflection gọi `SurfaceControl` / `DisplayControl` (tương thích Android 14/15/16 với `READ_FRAME_BUFFER` / `CAPTURE_VIDEO_OUTPUT`). Nén ảnh thành JPEG (quality 70, resize cạnh dài tối đa 1280px để tối ưu tốc độ mạng) và trả về chuỗi Base64.
   - `POST /action`: Nhận JSON điều khiển UI và thực thi qua Reflection gọi `InputManager.getInstance().injectInputEvent(event, INJECT_INPUT_EVENT_MODE_ASYNC)` (với quyền `INJECT_EVENTS`):
     - `{"type": "tap", "x": 500, "y": 500}` (tọa độ chuẩn hóa `0-1000`, tự quy đổi sang pixel thực tế của màn hình).
     - `{"type": "swipe", "x1": 500, "y1": 800, "x2": 500, "y2": 200, "duration": 300}`.
     - `{"type": "text", "content": "..."}` (bơm văn bản hoặc dùng lệnh `input text` / `ClipboardManager` + paste event để hỗ trợ tiếng Việt có dấu).
     - `{"type": "key", "keycode": 4}` (Back = 4, Home = 3, Recents = 187).
   - `GET /ui_info`: Trả về độ phân giải màn hình hiện tại, package name của app đang mở ở foreground (`UsageStatsManager` / `ActivityTaskManager`).
2. **File `AndroidManifest.xml` & `build.gradle.kts`:** Khai báo đầy đủ quyền hệ thống (`INJECT_EVENTS`, `READ_FRAME_BUFFER`, `CAPTURE_VIDEO_OUTPUT`, `FOREGROUND_SERVICE_SPECIAL_USE`, `RECEIVE_BOOT_COMPLETED`) và `BroadcastReceiver` tự động khởi chạy Service ngay khi thiết bị boot xong.

### PHẦN 2: MAGISK MODULE (`ai_os_bridge.zip`)
Cung cấp đầy đủ nội dung từng file để đóng gói thành Magisk Module mount APK trên vào `/system/priv-app`:
1. `module.prop`: Khai báo metadata chuẩn.
2. `system/etc/permissions/privapp-permissions-ai.os.bridge.xml`: Cấp whitelist chính xác cho toàn bộ quyền `signature|privileged` của package `ai.os.bridge` để **tuyệt đối tránh bootloop** do `PackageManager` chặn.
3. `service.sh`: Đợi `sys.boot_completed` = 1, kiểm tra cấp quyền runtime qua `pm grant` nếu cần, và gọi `am start-foreground-service` để đánh thức `AiOsBridge`.
4. Script bash `build_module.sh`: Tự động copy `app-release.apk` vào đúng cấu trúc thư mục và nén thành file `ai_os_bridge.zip` chuẩn.

### PHẦN 3: PYTHON ORCHESTRATOR AGENT (CHẠY TRÊN TERMUX / CHROOT)
Viết script `agent.py` sử dụng SDK chính thức `google-genai` (`pip install google-genai requests pillow`) kết nối trực tiếp với **Google AI Studio API** (sử dụng model `gemini-3.8-flash` hoặc `gemini-2.5-flash`):
1. **Vòng lặp nhận thức - hành động (Perception-Action Loop):**
   - Nhận câu lệnh mục tiêu từ người dùng (ví dụ: *"Mở Shopee, tìm mạch ESP32-S3 SuperMini và sắp xếp theo giá từ thấp đến cao"*).
   - Gọi `GET http://127.0.0.1:8765/screenshot` để lấy ảnh màn hình hiện tại.
   - Gửi ảnh kèm lịch sử hành động trước đó lên Gemini API với `System Instruction` ép trả về **Structured JSON Output** (`response_mime_type="application/json"`) gồm: `thought` (suy luận ngắn), `action` (`tap`, `swipe`, `text`, `key`, `wait`, `done`), tọa độ chuẩn hóa `[0-1000]`, và `status`.
   - Gửi lệnh tới `POST http://127.0.0.1:8765/action`, nghỉ `1.2s` cho UI ổn định rồi lặp lại cho tới khi `action == "done"` hoặc chạm giới hạn `max_steps = 15`.
2. **An toàn & Tối ưu:**
   - Cấu hình `SafetySetting` ở mức `BLOCK_NONE` để không bị chặn nhầm khi đọc nội dung màn hình cá nhân.
   - Tích hợp **SQLite Memory cục bộ (`agent_memory.db`)** lưu lại các chuỗi thao tác thành công (skill cache) để các lần sau thực thi nhanh hơn.
   - Giới hạn cứng số request/phút và tự dừng nếu phát hiện 3 bước liên tiếp màn hình không thay đổi (tránh kẹt vòng lặp đốt credit).
